## Default Permission

Default permissions for the VasakOS contextual menu plugin.

#### This default permission set includes the following:

- `allow-open-menu-window`
- `allow-close-menu-window`
- `allow-take-pending-menu`
- `allow-resolve-menu`
- `allow-show-menu-window`
